#Fraud Detection System

Application de détection de fraude basée sur le Machine Learning avec interface graphique.

##Performance
- **  Accuracy : 94%  **
- Modèle : Logistic Regression avec Pipeline sklearn

##Technologies
- Python, Scikit-learn, Streamlit, Pandas, Numpy

## Lancer en local
pip install -r requirements.txt
streamlit run fraud_detection.py

## 📁 Dataset
- AIML Dataset.csv
